# Committee reports — receiving vs. adopting

**Short answer:** Once a report's been read, it's been received. There's no motion to "receive" it. If the report is just information, no vote is needed. If it makes recommendations, the motion is to *adopt* them, which commits the group to them. "Accept" means the same as "adopt." So don't vote to accept a report unless you mean to endorse it.

## How it works

**The chair calls for reports in order.** That's officers and standing committees first, then special committees in the order they were appointed. The person giving the report, usually the committee chair, reads it and hands it to the chair or the secretary.

**What happens next depends on the kind of report:**

| The report… | What to do |
|---|---|
| Only gives facts or progress | Nothing. It's information. If the group does want to endorse it, the motion is to accept it, made by someone other than the reporter. |
| Is financial | Refer it to the auditors (see [Treasurer's report](treasurers-report.md)) |
| Ends with recommendations | The reporting member moves to adopt the recommendations. |
| Ends with resolutions | The reporting member moves to adopt the resolutions. Robert's says this is the best form. |
| Returns a motion that was referred | The chair takes up any pending amendments first, and then the motion. The committee's recommendation decides how the question is stated. |
| Is from a nominating committee | No vote on the report. The names are nominations, like ones made from the floor. |

**Write recommendations as motions.** Robert's says a committee should end its report with the exact resolutions it wants adopted, so the group only has to vote. "Your committee thinks the bill should be paid" leaves the effect unclear. Instead, write "Resolved, That the treasurer pay the bill of $____."

**The group can amend what it adopts, but not the report itself.** If the group strikes a recommendation before adopting, that changes what the group adopts. The committee's report still says what it said.

**A partial report** is handled like a final one. If it only reports progress, no action's needed. If it recommends action, put the question on that.

**Once the final report is received,** the committee's work is done. A special committee ceases to exist without any motion.

## Minority views

When some committee members disagree, they can submit their views in writing. These are usually read right after the chair states the question on the committee's report. If anyone objects to hearing them, it takes a majority vote, without debate, to receive them. The minority's views are for information. They can only be acted on if someone moves to substitute the minority's recommendations for the committee's. The majority's report *is* the committee's report, and Robert's says it should never be called "the majority report."

## Watch out for

- **"I move we receive the report."** It's already been received by being read.
- **"I move we accept the report"** when you only mean "we heard it." Accepting a report endorses it. Robert's calls that mistake "less common, but dangerous."
- **A report the committee never agreed on.** A committee's report can only include what a majority agreed to at a meeting all members were notified of, with a quorum present. If meeting isn't practical, it can include only what every member agrees to.
