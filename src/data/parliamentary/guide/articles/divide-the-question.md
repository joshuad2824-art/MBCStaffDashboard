# Splitting a motion into parts — "Division of the Question"

**Short answer:** When a motion contains several things that could each stand alone, the group can split it and vote on each part separately. If the parts are on unrelated subjects, any one member can require the split. If they're on the same subject, it takes a motion and a majority vote.

`Second: Yes · Debate: No · Amend: Yes · Vote: Majority · Interrupt a speaker: No (for unrelated items: no second, no vote, and it can interrupt)`

**What to say:**

- Unrelated items: "I ask that the question be divided."
- Same subject: "I move to divide the motion so that we vote separately on the new copier and on the service contract."

## How it works

**Usually it's done by agreement.** Most of the time the chair just asks if there's any objection to taking the parts separately. A formal motion is only needed when someone objects, and that motion has to say exactly how to split it.

**Each part has to make sense on its own.** The secretary should be able to separate the parts mechanically, maybe adding "That" to the front of each one, without rewriting anything. Each part also has to be something the group could adopt even if every other part failed. If it can't be separated without rewriting, it can't be divided.

**Some things can't be divided:**

- **"Refer with instructions"** can't be split. If the referral failed, the instructions would have no committee to go to.
- **"Strike out and insert"** is one proposition.

**When a committee reports several amendments,** the group can adopt them all in one vote. But if a single member asks for a separate vote on one of them, that one gets its own vote.

## Going paragraph by paragraph instead

For a long document whose parts depend on each other, like a set of bylaws or a long report, don't divide it. Take it up paragraph by paragraph, also called *seriatim*:

1. Read the first paragraph and take amendments to it. Don't vote to adopt it yet.
2. Do the same with each paragraph that follows.
3. When the chair has gone through them all, the whole document is open for more amendments.
4. Amend the preamble, if there is one, last.
5. Take a single vote on adopting the whole thing.

The chair should do it this way on their own initiative with any multi-paragraph document. If the chair doesn't, anyone can move to consider it by paragraph.

## Watch out for

- **Insisting on a split of one complicated proposal.** Nobody has a *right* to divide a single proposal, however complicated it is. Your remedy is to move to divide it if it can be divided, or else to move to strike out the part you object to.
- **Adopting paragraphs one at a time.** If a later paragraph changes something, you'd have to [reconsider](reconsider.md) an earlier one. With bylaws it's worse, since each one takes effect the moment it's adopted.
